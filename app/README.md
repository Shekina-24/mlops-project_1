# Bias in Bios — Profession Classifier & Fairness Audit

Educational demo pairing a résumé/CV profession classifier with a gender bias audit, built on the
[LabHC/bias_in_bios](https://huggingface.co/datasets/LabHC/bias_in_bios) dataset.

Model: [S12-24/bias-in-bios-profession-classifier](https://huggingface.co/S12-24/bias-in-bios-profession-classifier)

Source code: [GitHub — Shekina-24/mlops-project_1](https://github.com/Shekina-24/mlops-project_1)
